## 3. ShopEase Project for Resume

```
Project: ShopEase — E-Commerce Platform
Tech Stack: Java 17, Spring Boot 3.x, Spring Cloud, Angular 17,
            MySQL, Redis, Kafka, Docker, Kubernetes, Jenkins, AWS

Description: A real-time microservice-based e-commerce platform
containing 7 microservices: Product Service, Order Service,
User Service, Notification Service, API Gateway, Service Registry
(Eureka), and Config Server. The system handles product catalog,
order processing, user authentication (JWT), and real-time email
notifications via Kafka.

Roles & Responsibilities:
• Designed and developed RESTful APIs for Product and Order microservices
• Implemented JWT-based authentication and authorization using Spring Security
• Integrated Apache Kafka for async order notification processing
• Used Redis caching to optimize product catalog read performance
• Wrote JUnit 5 + Mockito unit tests achieving 85% code coverage
• Fixed SonarQube code quality issues (bugs, code smells, vulnerabilities)
• Containerized all services using Docker and Docker Compose
• Deployed to AWS EC2 with RDS (MySQL) for database
• Created Jenkins CI/CD pipelines for automated build and deployment
• Participated in Agile/Scrum ceremonies and managed stories in JIRA
```

## 4. Company Joining Formalities

| Step | Details |
|---|---|
| **Onboarding** | Meet HR, fill documents, get ID card, collect laptop |
| **Induction** | HR explains company policies, benefits |
| **Meeting with RM** | Resource Manager → Project allocation based on skills |
| **Project Interview** | Tech team checks if your skills match the project |
| **KT Sessions** | Knowledge Transfer — learn the existing codebase |
| **Task Assignment** | Get JIRA stories assigned, join daily scrum |

---

## 5. Exit Formalities

```
1. Get offer from new company
2. Setup one-to-one with manager → inform about resignation
3. Submit resignation in HR portal
4. HR confirms notice period & last working date
5. During notice period → Give KT to team
6. Last day → Submit ID card, laptop, belongings
7. Last day → Give lunch party to team 🎉
8. Download: Payslips, Form 16, Experience letter, Relieving letter
9. Full & Final settlement → within 30 days
```

## 7. Do's and Don'ts

### ✅ Do's

| # | Practice |
|---|---|
| 1 | Maintain friendly relationships with team |
| 2 | Setup monthly one-to-one with manager (showcase work) |
| 3 | Provide KT to new team members |
| 4 | Conduct internal trainings on new technologies |

### ❌ Don'ts

| # | Avoid |
|---|---|
| 1 | Don't discuss or ask about salary with team members |
| 2 | Don't send project/client docs to personal email |
| 3 | Don't use social media on company systems |
| 4 | Don't abscond from the company |

## 8. Common Interview Topics

| # | Topic | Preparation Focus |
|---|---|---|
| 1 | **Self Introduction** | 2-3 min structured intro |
| 2 | **Roles & Responsibilities** | ShopEase project details |
| 3 | **Challenges Faced** | DB optimization, integration issues |
| 4 | **Multi Threading** | Bulk notification scenario |
| 5 | **Microservices Concepts** | Service discovery, circuit breaker |
| 6 | **Spring Security** | JWT flow explanation |
| 7 | **Docker / K8S** | Container orchestration concepts |
| 8 | **CI/CD Pipeline** | Jenkins pipeline stages |

### Sample Self Introduction

```
"Hi, I'm Surya Pandey. I have experience as a Java Fullstack Developer
working with Spring Boot Microservices, Angular, and AWS.

In my current project — ShopEase, an e-commerce platform — I'm responsible
for developing Product and Order microservices, implementing JWT
authentication, integrating Kafka for async notifications, and setting up
Docker containerization.

I've also worked with Redis for caching, JUnit/Mockito for unit testing,
and Jenkins for CI/CD pipelines. I enjoy solving complex backend challenges
and continuously learning new technologies."
```
